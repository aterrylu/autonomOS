## ADR-101: One "Idle" label for ready + idle, and the passive label fades with recency

- **Date:** 2026-09-24 · **Decided by:** Terry (picks T1 + (a) from an artifact round, via TeamLead); Claude (implementation)
- **Context:** Two sidebar-status asks. (1) The B2 timestamp already fades with age; Terry wanted to see the Ready/Idle label recede the same way on stale rows. This revisits the status×recency interaction he declined earlier as too complex (ADR-090 follow-up), now scoped to passive statuses only. (2) Terry was confused by "Ready" vs "Idle". In the code, Ready = `SessionStart` (startup, **resume**, or **/clear**, plus a compaction resolved with no baseline) and Idle = `Stop`. Both mean "not busy, waiting for input", and they already share the green dot and the sage label color. Ready does NOT mean "never prompted": a resumed agent with hundreds of turns shows Ready. Codex has no SessionStart and never emits `ready`: a fresh Codex thread is `idle` until its first turn, so the same state read "Ready" on Claude/Gemini and "Idle" on Codex. [Options artifact](https://claude.ai/artifact/PQW77xfPrNPcQwi3p5bVbd).
- **Decision:** (T1) A passive (`ready`/`idle`) status label fades on the SAME theme-aware ramp as its row's timestamp (`recencyLabelOpacity` in `recency.ts`, reusing `recencyBucket` + `RECENCY_OPACITY_DARK/LIGHT`; same `lastActive`, same ~5s render cadence, no new timer). The status dot stays full. `needs_input`, `error`, the active-work shimmer, and `stopped` never fade. (a) `agentStatusLabel("ready")` returns "Idle", display-only. The server keeps both states (idle stickiness against late tool events, `restoredStatus()`'s ready fallback, and the prompt-delivery tracker, which reads hook events, not labels, are all unchanged).
- **Rationale:** One shared ramp makes the row's right edge recede as a unit and can never disagree with the timestamp beside it. Exempting attention statuses keeps a stale row that needs you at full strength. The dot stays full because it is the at-a-glance "alive" signal. "Idle" over "Ready": it matches what Codex already shows, the icon's own aria-label, and reads naturally beside an old "34d".
- **Alternatives considered:** **T2 gentler ramp** and **T3 dot fades too**: not picked. **(a′) one label "Ready"**: friendlier, but odd on a month-old row. **(b) "Fresh"/"Done"**: rejected because the names promise a "never prompted" meaning the data does not carry (resume and /clear also fire SessionStart; Codex never would). **(c) Idle + a never-prompted cue**: only honest with a new persisted "has completed a turn" field fed from all three providers. That is a feature, not a relabel, and it can layer onto (a) later if wanted.
- **Source:** Terry via TeamLead over the autonomOS agent channel, 2026-09-24.
