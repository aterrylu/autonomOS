## ADR-118: Org chart cards: stacked reports and the Balanced card, fed by one batched request

- **Date:** 2026-09-26
- **Decided by:** Terry ("Stacked reports plus the recommended Balanced looks good, let's goooo", relayed by TeamLead), built by OrgChart@autonomOS.
- **Context:** Terry: "The agent cards … should ideally be closer together … more fun and have more info than they currently have." Reports laid out side by side made a chart's width grow with the number of agents: a 17-agent fleet opened at 60% and needed the map. Cards showed a status label and an age, but none of the inspector's history.
- **Decision:**
  1. **Stacked reports (density option C).** A lead's LEAF reports hang in a column off a spine, like the sidebar; reports that lead teams, or are folded teams, stay side by side (their rollup chips need headroom). Width now grows with teams, not agents: the same 17-agent fleet fits whole at 100%. Gaps tightened (H 18, V 44). `edgePath()` is the one connector used by the renderer and message envelopes; arrow keys walk a column; card rects stay in `layout.pos` so PR 4's drop targets hit-test stacked columns like any card.
  2. **The Balanced card** (same 200 × 60): an identicon seeded by the agent's ID (not its name, so same-named agents still differ), with the real provider/status icon, unaltered, as its badge; name + an unread count pill; a pulsing dot while working or waiting on you; the live action (the existing status label, so Codex reads "Working", never a guessed tool); time in state; a thin 24-hour strip along the bottom edge.
  3. **One batched request feeds every card**: `GET /api/agents/analytics` (the batch endpoint) returns each agent's status-since and 24h strip, down-sampled to 48 segments (a bucket with any needs-input shows needs-input), sharing `activityStrip()` with the inspector's route. The dashboard fetches it on mount, every 20s while visible, and soon after any status change (debounced).
  4. **Honesty rules hold:** no field shows a number the runtime can't report. Time in state falls back to the last-active age, titled as such, when the server has no history; the context-% ring waits for TerminalRender's statusline feed; no permission-mode chips; runtime color is not used (provider marks stay unaltered).
- **Rationale:** stacking attacks width, which is what forced the 60% floor and the map; everything else about the chart (rollups, folding, the canvas, message flow) keeps working because the layout still returns one rect per card and one path per edge. Pulling the inspector's history onto the card needed a batched feed: N per-card requests every 20s would scale with the fleet.
- **Alternatives considered:** tighter gaps only (option A) and a compact 150 × 44 card (B): both still opened a 24-agent fleet at the floor with the map, and B has no room for the live action; a Comfortable/Compact toggle (a B variant); the Calm card (less information) and the Playful card (taller, and its context ring has no data source yet); per-card analytics fetches (N requests per refresh).
