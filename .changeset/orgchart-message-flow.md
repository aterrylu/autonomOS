Org Chart message flow: when one agent messages another, an envelope travels along the chart and a speech bubble pops up on the recipient with a one-line preview (bursts collapse into "+N"). Hover a bubble for the full message; the agent inspector shows who each agent talks to and its recent messages. Messages can be set to Animated, Quiet, or Off.
