Org Chart inspector gets real analytics: how long an agent has been in its current state, uptime, turns, how often and how long it waited on you, tool calls by tool (and failures), restarts and crashes, a timeline strip of its activity, and its git branch, in collapsible sections. Fields a runtime can't report (e.g. Codex tool calls) show "n/a" instead of a misleading zero.
