Update from the dashboard. The "New release available" pill now opens an in-app flow: every release's notes since your version (the same notes published on GitHub, rendered safely), a pre-flight that shows which agents are mid-task and what a restart would cost them, and a default of **waiting until all agents have been idle for 30 seconds** before updating (or update now, or cancel). The update runs out of band as its own service job — surviving the restart it causes — with the existing health check and automatic rollback; the dashboard shows progress, reconnects on its own, and reloads onto the new version. Installs not running as a service get the terminal command instead. Before anything changes it saves a snapshot of your agents' setup (`autonomos snapshots list`); afterwards it verifies every agent that was resumable still is, and flags any that isn't next to a **Restore previous version** action — which, like `autonomos rollback` and the automatic rollback, now restores the previous version *and* its snapshot together. Agents cannot trigger it. (ADR-101)
